Kuroma Channel Tools（チャンネル運営ツール）

ひとりの運営者が、自分の YouTube チャンネルの動画を投稿・管理するために使うツールです。Google Cloud のプロジェクト quiz-shorts-youtube だけを使います。

日本語 ・ English

このツールについて

運営者（くろま あくと）が自分で運営している YouTube チャンネルに動画を上げ、公開の予約をし、題名・説明欄・再生リストを更新し、自分のチャンネルの再生数などを確かめるための、個人用のツールです。

運営者のパソコンの中で動くプログラム（と、運営者の GitHub のリポジトリで動く投稿用のプログラム）で、一般の人に向けたサービスではありません。運営者以外の人がログインして使うことはありません。

使うチャンネル

運営者が持つ次の13チャンネルです：東大院試サークルESCAPE、ESCAPE Consulting Career、カメとリスのお金ノート、目を細めて脳トレ、Squint Quiz、建築・インフラのなぜ、毎日10秒 都道府県脳トレ、Map Ratio、Escape Physics、データ番付、The Zodiac Scoreboard、Country Ball Race、記録で見る昔の日本。

使う YouTube API サービスの機能

  • youtube.upload：自分のチャンネルへの動画のアップロードと、公開日時の予約
  • youtube.readonly：自分のチャンネル・動画・再生リスト・コメントの情報の読み取り
  • youtube.force-ssl：自分の動画の題名・説明欄・再生リストの更新
  • yt-analytics.readonly：自分のチャンネルの再生数などの統計の読み取り

About this app

Kuroma Channel Tools is a private tool used only by one operator (Kuroma Akuto) to manage the operator's own YouTube channels. It uploads videos to the operator's own channels, schedules their publication, updates titles, descriptions and playlists of the operator's own videos, and reads the operator's own channel statistics through the YouTube API Services. It uses a single Google Cloud project, quiz-shorts-youtube.

It runs on the operator's own computer (and in the operator's own GitHub repository for scheduled uploads). It is not offered to the public, and no one other than the operator signs in to it.

Channels

The 13 channels owned and operated by the operator: 東大院試サークルESCAPE, ESCAPE Consulting Career, カメとリスのお金ノート, 目を細めて脳トレ, Squint Quiz, 建築・インフラのなぜ, 毎日10秒 都道府県脳トレ, Map Ratio, Escape Physics, データ番付, The Zodiac Scoreboard, Country Ball Race, 記録で見る昔の日本.

YouTube API Services scopes used

  • youtube.upload: Upload videos to the operator's own channels and schedule their publication
  • youtube.readonly: Read information about the operator's own channels, videos, playlists and comments
  • youtube.force-ssl: Update the titles, descriptions and playlists of the operator's own videos
  • yt-analytics.readonly: Read view counts and other statistics of the operator's own channels
